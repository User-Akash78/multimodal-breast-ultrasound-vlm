This folder contains the results produced by the final evaluation stage of the breast ultrasound multimodal analysis system.

The files in this folder are generated from the held-out test set after model training and model selection are complete.


Files:
final_evaluation_summary.csv
    Contains the overall performance metrics for the completed system.

test_classification_results.csv
    Contains per-case classification and segmentation results for the test set.

efficientnet_image_only_results.csv
    Contains the efficientnet baseline classification results for comparison 

report_generation_results.csv
    Contains the generated and reference reports for the test set.
